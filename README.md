# Listen & Save Docs

Consegue criar um aplicativo que leia em voz alta documentos PDF ou outros tipo que independente ficar o texto e que tenha como salvar o áudio MP3 ou W a V? E se tiver mais uma página ele muda a página mas também tem que ter os voltar recomeçar play pause

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://your-audio-doc.lovable.app
